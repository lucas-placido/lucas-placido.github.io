## Objetivo
Projeto de estudo focado em **infraestrutura como código**: provisionar uma pipeline de dados na AWS de forma reproduzível, do zero, usando **Terraform**.

## O que demonstra
- **Provisionamento com Terraform** (`terraform init` / `apply`) de toda a infraestrutura.
- Configuração de credenciais e geração de par de chaves para acesso **SSH à instância EC2**.
- Estrutura de projeto organizada para reaproveitar e versionar a infra.

## Stack
`AWS` · `Terraform` · `EC2`
